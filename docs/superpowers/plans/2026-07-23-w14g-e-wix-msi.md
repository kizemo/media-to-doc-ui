## Task 5: sandbox-verify 验 MSI

**Files:** 不改,只跑脚本

- [ ] **Step 5.1: 读 sandbox-verify 脚本,确认是否支持 .msi**

- [ ] **Step 5.2: 跑 sandbox-verify MSI**

Run:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "F:\soft\00selfmade\sandbox-verify\media-to-doc-ui\mtd-verify.ps1" -InstallerPath "F:\soft\00selfmade\media-to-doc-ui\target\release\bundle\msi\media-to-doc_1.4.0_x64_zh-CN.msi" -NoWait 2>&1 | tee /tmp/w14g-verify.log
```
Expected: 沙箱弹窗显示安装 UI,可选 `-NoWait` 让用户观察日志流。

- [ ] **Step 5.3: 验 sandbox 装完 MSI 后进程在跑 + 产物落地**

等安装完成(MSI 通常 ~30s),检查:
- `C:\Users\Duanyi\sandbox-artifacts\mtd\logs\verify.log` exit 0
- 沙箱里 `media-to-doc-ui.exe` 进程已起,标题 "media-to-doc"

- [ ] **Step 5.4: 若 sandbox-verify 不识别 .msi(已撞)**

错误模式:`in-sandbox-verify.ps1:29-32` 只识别 `*-setup.exe` / `*-portable.exe` → sandbox 报 `未找到 installer 或 portable` → exit 2 FAIL。
本会话决策:**跳过 sandbox-verify 跑 MSI**,只验证 build 产物路径 + 体积 + 在用户桌面手动跑 MSI 装机(脱离 sandbox-verify)。
sandbox-verify 扩展 MSI 支持留作 W14-G+ 候选:
- `in-sandbox-verify.ps1` 加 `*.msi` glob
- 新加 `lib/Install-MsiSilent.ps1`(用 `msiexec /qn /i ... /l*v <log>`)
- `lib/Get-InstallerType.ps1` 加 MSI 分支(OLE `D0 CF 11 E0` magic)
- 卸载用 `msiexec /x {ProductCode} /qn`
